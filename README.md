# Webora Tec Multi-Page Business Website

A premium multi-page business website built with HTML, CSS, and JavaScript. The project includes a modern dark UI with blue and purple gradients, glassmorphism cards, responsive layout, mobile navigation, and a validated contact form.

## Project Overview

This website is designed for a digital agency / business brand and includes:
- Home page
- About page
- Services page
- Contact page
- Responsive navigation menu
- Modern glassmorphism design
- Smooth hover and button animations
- Client testimonials and CTA sections
- Front-end form validation for the contact form

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts (Outfit)

## Run Locally

Open the project in a browser directly, or run a local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Features

- Responsive layout for desktop, tablet, and mobile
- Sticky navigation with mobile menu toggle
- Premium dark agency aesthetic
- Blue and purple gradient accents
- Glassmorphism effect cards
- Hover animations and polished buttons
- Contact form validation with success/error messages
- Accessibility-friendly focus states
